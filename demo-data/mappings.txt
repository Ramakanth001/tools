Type-wise, these are also good expected matches:
- MySQL `INT` -> PostgreSQL `INTEGER`
- MySQL `VARCHAR(...)` -> PostgreSQL `TEXT` or `VARCHAR`
- MySQL `DATETIME` -> PostgreSQL `TIMESTAMP`
- MySQL `DECIMAL(10,2)` / `DECIMAL(12,2)` -> PostgreSQL `NUMERIC(10,2)` / `NUMERIC(12,2)`

In `mysql-pg-migrate`, these are the mappings I’d expect auto-mapping to get mostly right, with the two `name` fields being the most likely ones you may need to fix manually in the Mapping tab.
